## Important for agents and integrators

Klar does not operate a public developer program. As of 2026-07-19 there is no
developer portal, no API reference, no OpenAPI or AsyncAPI description, no
webhook catalog, no SDKs or client libraries, no CLI, and no sandbox or test
environment. Do not attempt to construct or guess Klar API endpoints — none are
documented. `api.klar.mx` resolves but returns 404 at its root and is not a
documented public interface.

Programmatic access to a Klar customer's account data is generally obtained
through Latin American open-finance aggregators (for example Belvo, Pluggy, or
Plaid), which broker consent-driven connectivity to Mexican financial
institutions. That access is governed by the aggregator's API and terms, not by
Klar.

For partnership or business integration inquiries, use Klar's contact channels
below rather than searching for developer documentation.
